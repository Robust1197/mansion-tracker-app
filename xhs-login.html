小红书重新登录

当 Mansion Tracker 显示“小红书登录失效 / 安全验证”时，用这个助手更新登录态。

最简单的方法（Windows）

  1. 下载下面的登录助手。
  2. 在下载目录里右键 xhs-login.ps1 → 使用 PowerShell 运行。
  3. 脚本会弹出一个真实 Chromium 窗口。正常登录小红书，包括扫码、短信或安全验证。
  4. 确认能看到小红书首页后，回到 PowerShell 窗口按 Enter。
  5. 脚本会自动把登录态写入私有 GitHub Secret，并自动触发一次抓取。
下载小红书登录助手 返回 Mansion Tracker

安全说明

脚本不会把 Cookie 打印到屏幕，也不会提交到公开仓库。登录态只暂存在你电脑的临时目录，随后直接写入私有仓库的 GitHub Actions Secret XHS_STORAGE_STATE_B64，完成后临时文件会删除。

第一次运行可能自动安装 GitHub CLI / Playwright Chromium。以后重新登录通常只需要打开脚本、登录小红书、按 Enter。
