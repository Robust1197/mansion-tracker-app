小红书重新登录

当 Mansion Tracker 显示“小红书登录失效 / 安全验证”时，可以直接在 Android 手机或 Windows 上恢复登录。

📱 Android 手机登录（推荐）

安装一次“小红书登录助手”。以后不需要电脑，也不需要复制 Cookie。

  1. 下载并安装下面的 APK。
  2. 第一次打开时点 设置 GitHub Token。创建一个 Fine-grained Token，只授权两个仓库：pathToFreedeom 和 mansion-tracker-app。
  3. Token 权限设为：Secrets → Read and write、Actions → Read and write、Contents → Read and write。Repository access 只选择 pathToFreedeom 和 mansion-tracker-app。
  4. 在助手里的真实小红书 WebView 正常登录，包括短信或安全验证。
  5. 显示“已检测到小红书登录态”后，点 登录完成 → 上传登录态。
  6. 助手会在手机上用 GitHub 仓库公钥加密 Cookie，更新 XHS_COOKIE；同时把同一个受限 Token 安全保存为 PUBLIC_REPO_TOKEN，恢复私有仓库到公开 App 的自动同步，然后触发一次抓取。
创建正确权限的 GitHub Token 打开已安装的登录助手 下载 Android 登录助手 APK

GitHub Token 使用 Android Keystore 加密保存在本机。小红书 Cookie 不会写进公开仓库，也不会经过剪贴板。

💻 Windows 备用方法

  1. 下载登录助手脚本。
  2. 右键 xhs-login.ps1 → 使用 PowerShell 运行。
  3. 在弹出的 Chromium 中正常登录小红书。
  4. 确认登录完成后回到 PowerShell 按 Enter。
  5. 脚本会更新私有 GitHub Secret 并触发一次抓取。
下载 Windows 登录助手

安全说明

Android：WebView 登录态由 Android CookieManager 读取，然后使用 GitHub Actions Secret 的仓库公钥在设备端加密后上传。GitHub Token 仅保存在 Android Keystore 加密存储中。

Windows：登录态只暂存在电脑临时目录，写入私有 GitHub Secret 后自动删除。
