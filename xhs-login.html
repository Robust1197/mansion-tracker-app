小红书重新登录

当 Mansion Tracker 显示“小红书登录失效 / 安全验证”时，在手机或 Windows 上更新登录态。

📱 Android 手机登录

推荐日常使用这个方法。只需要第一次安装登录助手 APK。

  1. 下载并安装“小红书登录助手”。如果 Android 提示未知来源，请只对当前浏览器允许这一次安装。
  2. 打开助手，在里面的真实小红书页面正常登录，包括短信、扫码或安全验证。
  3. 顶部显示“已检测到小红书登录态”后，点 同步登录态。
  4. 助手会复制登录态并自动打开你的私有 GitHub Secret 页面。
  5. Name 填 XHS_COOKIE，Secret 直接粘贴，然后点 Add secret。
  6. 回到登录助手，点“清除剪贴板”。下一次抓取会自动使用新的登录态。
下载 Android 登录助手 APK

APK 源码公开在 mansion-tracker-app 仓库中；它不会把小红书登录态发送到第三方服务器。

💻 Windows 登录

  1. 下载登录助手脚本。
  2. 在下载目录里右键 xhs-login.ps1 → 使用 PowerShell 运行。
  3. 脚本会弹出真实 Chromium，小红书正常登录。
  4. 确认首页能正常使用后，回到 PowerShell 按 Enter。
  5. 脚本会自动把登录态写入私有 GitHub Secret，并触发一次抓取。
下载 Windows 登录助手

安全说明

Android：登录态只存在助手 WebView 和手机剪贴板中；你自己把它粘贴到私有 GitHub Secret。完成后建议立刻点“清除剪贴板”。

Windows：登录态只暂存在电脑临时目录，随后直接写入私有 GitHub Secret，临时文件自动删除。
